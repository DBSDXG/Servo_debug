# 舵机调试助手 (Servo Debug Tool)

基于 **PyQt5 + pyserial** 的舵机调试上位机，通过串口向 STM32 下位机发送 PWM 脉宽指令控制舵机角度。

## 功能

- 串口设置：端口自动枚举、常用波特率、8N1 格式
- **舵机类型选择**：180° / 270°（另附 90°、360°），切换后角度范围自动调整
- **角度 → PWM 标定**：可设置 0° 对应的最小脉宽、最大角对应的最大脉宽（默认 500~2500us），线性映射；附常用脉宽预设按钮
- 角度控制：滑块 + 数值框联动，可勾选"拖动滑块时自动发送"（30ms 节流）
- **复位按钮**：一键回到中位（180° 舵机即 90°，270° 舵机即 135°）
- 手动 PWM 微调：±1 / ±10 / ±100 us 按钮便于标定极限脉宽
- 通信日志：收发数据带时间戳，接收可切换 HEX 显示
- 配置自动保存（`servo_config.json`），下次启动自动恢复

## 依赖安装与运行

**方式一：直接双击 EXE（推荐，无需安装 Python）**

双击文件夹中的 `舵机调试助手.exe` 即可运行（单文件版，约 39MB）。

- 首次启动需几秒解压，属正常现象
- 配置文件 `servo_config.json` 保存在 exe 同目录，删掉它即恢复默认设置
- 若复制到其他电脑时系统弹出 SmartScreen 提示，点"更多信息 → 仍要运行"即可（未签名的自编译程序都会有此提示）

**方式二：源码运行**

```bash
pip install PyQt5 pyserial
python servo_debug.py
```

**重新打包 EXE（修改源码后）**

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name ServoDebug servo_debug.py
```

打包产物在 `dist\ServoDebug.exe`，可自行重命名（如 `舵机调试助手.exe`）；
`build\` 目录和 `.spec` 文件为中间产物，可删除。

## 串口协议（上位机 → STM32）

### 1. 物理层参数

| 参数 | 值 |
|------|-----|
| 波特率 | 默认 **115200**（界面可选 9600 ~ 921600） |
| 数据位 | 8 |
| 校验位 | 无 (None) |
| 停止位 | 1 |
| 流控 | 无 |
| 通信方式 | 全双工，单向发送指令，下位机无需应答 |

即固定 **8N1** 格式。

### 2. 数据类型（重要）

上位机发送的是 **ASCII 纯文本（可打印字符），不是二进制 / 不是 HEX 帧**：

- 帧结构：`指令名 + 冒号参数 + 换行符`，**无帧头、无长度字节、无校验和**
- 帧尾固定为换行符 `\n`（即字节 `0x0A`），下位机按行解析即可
- 所有字符均为 ASCII（每字节 < 0x80），可直接用 `strcmp` / `atoi` 处理
- 指令名区分大小写，固定大写

只有以下 **2 种指令帧**：

| 指令格式 | 说明 | 参数范围 |
|----------|------|----------|
| `PWM:<脉宽us>\n` | 设置舵机脉宽，数值为十进制整数微秒 | 由界面标定值决定（默认 500~2500） |
| `RESET\n` | 复位请求（上位机会紧跟着再发一帧中位 PWM，下位机可忽略本帧） | 无参数 |

### 3. 字节级示例

以 `PWM:1500\n` 为例，实际串口线上发出的 9 个字节：

| 内容 | `P` | `W` | `M` | `:` | `1` | `5` | `0` | `0` | `\n` |
|------|-----|-----|-----|-----|-----|-----|-----|-----|------|
| HEX  | 50  | 57  | 4D  | 3A  | 31  | 35  | 30  | 30  | 0A   |

常见完整帧：

| 界面操作 | 发送内容 | 实际字节 (HEX) |
|----------|----------|----------------|
| 角度 90° (180°舵机, 默认标定) | `PWM:1500\n` | `50 57 4D 3A 31 35 30 30 0A` (9 字节) |
| 角度 0° | `PWM:500\n` | `50 57 4D 3A 35 30 30 0A` (8 字节) |
| 角度 180° | `PWM:2500\n` | `50 57 4D 3A 32 35 30 30 0A` (9 字节) |
| 点击复位按钮 | `RESET\n` + `PWM:1500\n` | `52 45 53 45 54 0A` + `50 57 4D 3A 31 35 30 30 0A` |

> 注意脉宽位数不固定（8 或 9 字节），下位机解析必须以 `\n` 作为帧结束标志，不能按固定长度解析。

### 4. 发送时机与频率

| 触发方式 | 发送行为 |
|----------|----------|
| 点击"发送角度" / "发送 PWM" | 立即发送 1 帧 |
| 拖动滑块（勾选自动发送时） | 节流发送，**每 30ms 最多 1 帧**，只发最新值 |
| 点击 ±1/±10/±100 微调按钮 | 每次点击 1 帧 |
| 点击"复位"按钮 | 依次发送 `RESET\n` 和 `PWM:<中位>\n` 两帧 |

### 5. 下位机解析要点

1. 逐字节接收，遇到 `0x0A` 认为一帧结束（建议同时兼容 `\r\n`，忽略 `0x0D`）
2. 用前缀匹配区分指令：`strncmp(buf, "PWM:", 4) == 0` → 取 `atoi(buf+4)` 写入 CCR
3. 建议对脉宽做范围限幅（如 500~2500），防止异常值损坏舵机

角度→脉宽换算在**上位机**完成：`pwm = pmin + (pmax - pmin) × angle / max_angle`，
STM32 只需把收到的数值写入定时器 CCR 即可。

## STM32 参考实现

以标准库 / HAL 均可，核心是：50Hz PWM（周期 20ms）+ 解析串口行。以下为伪代码级参考：

```c
/* TIM 配置要点(以 72MHz 主频为例):
 *   预分频 = 72-1  → 计数频率 1MHz (1 tick = 1us)
 *   自动重装 = 20000-1 → 周期 20ms = 50Hz
 *   CCR = 脉宽(us)   例如 1500 → 1.5ms
 */

volatile uint8_t rx_buf[64];
volatile uint16_t rx_idx = 0;

/* 串口每收到一个字节调用一次(中断方式) */
void USART1_IRQHandler(void) {
    uint8_t ch = USART_ReceiveData(USART1);
    if (ch == '\n') {                       /* 一行结束, 开始解析 */
        rx_buf[rx_idx] = '\0';
        ParseLine((char *)rx_buf);
        rx_idx = 0;
    } else if (rx_idx < sizeof(rx_buf) - 1) {
        rx_buf[rx_idx++] = ch;
    }
}

void ParseLine(char *line) {
    if (strncmp(line, "PWM:", 4) == 0) {
        uint32_t us = atoi(line + 4);       /* 例如 "PWM:1500" → 1500 */
        if (us >= 500 && us <= 2500)
            TIM_SetCompare1(TIM3, us);      /* 写入 CCR, 舵机立即动作 */
    } else if (strcmp(line, "RESET") == 0) {
        TIM_SetCompare1(TIM3, 1500);        /* 回中位, 上位机随后也会发 PWM:1500 */
    }
}
```

> 提示：若用 HAL 库，在 `HAL_UART_RxCpltCallback`（配合逐字节接收或空闲中断）中做同样的行解析即可。

## 常见问题

- **检测不到串口**：安装 USB 转串口驱动（CH340 / CP2102 / FT232），插拔后点"刷新"
- **打开失败**：确认没有其他软件（串口助手、Keil 调试）占用该端口
- **舵机不动**：先确认 STM32 固件已按上述协议解析；再用手动 PWM 发送 1500，观察是否有动作
- **角度不准**：用"手动 PWM 控制"区找到机械 0° 与最大角的真实脉宽，填入"舵机参数"区重新标定
